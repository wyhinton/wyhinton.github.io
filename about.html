--- layout: page title: About permalink: /about/ --- Webb Hinton is a software engineer and designer living in the Los Angeles area. He works full-stack, with a lean toward the front end: state-heavy interfaces, data visualization, and the design systems that hold them together. For the last few years he's been the lead developer on a biosecurity data platform used across 34 U.S. states, where he built an interactive map editor from scratch, a data-ingestion pipeline connecting an Angular front end to a Java/Spring backend, and the shared component library the rest of the app is built on. Before that, he built kiosk software and web tools for NC State University Libraries, and worked as a research assistant building interactive maps for urban-equity research. He holds a Master's in Art and Design from NC State and a Bachelor's degree from UNC Chapel Hill (Anthropology, Philosophy, Entrepreneurship), a background that shows up in how he thinks about design as much as code. Outside of client and contract work, he maintains a couple of small open source projects: a set of examples for the FLTK Rust GUI library, and Awesome Houdini, a curated list of open-source tools for the Houdini 3D software. {% raw %}
